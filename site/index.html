Friday

A bilingual (Spanish / English) voice assistant for macOS that actually does things. Say “Jarvis”, ask, and Friday controls your Mac, its apps and Chrome — then answers out loud.

View on GitHub Build from source Download for Apple Silicon

A real recording of the running app. Friday is a native macOS app, so there is no in-browser demo — the same commands work by voice.

What it does

🎙️ Local wake word

“Jarvis” is detected on your Mac with sherpa-onnx — no key, no network. Train it to your own voice in a short lesson.

🗣️ Bilingual speech

On-device recognition in Spanish and English (even mixed), with your app, playlist and contact names.

🖥️ 136 Mac actions

Music, Reminders, Notes, Calendar, Mail, Messages, files, system controls — validated, permission-checked and verified.

🌐 Chrome agent

Browses, compares, fills forms and downloads for you, asking before anything risky.

🧠 Your choice of model

Sign in with ChatGPT, an OpenAI key, Ollama / LM Studio, Apple's on-device model — or none for everyday commands.

🔒 Private and safe

Keychain for secrets, a loopback-only token-protected sidecar, checksum-verified models, approvals for sends and deletes.

Install

Download: get the zip from the latest release (macOS 26+, Apple Silicon), drag Friday.app to Applications and confirm it once in System Settings ▸ Privacy & Security — it is not notarized. Step-by-step guide.

Or build it with Xcode 26.6 or newer and Homebrew. One command builds and launches it:

brew install xcodegen uv && git clone https://github.com/Ale-Newport/Friday.git && cd Friday && make bootstrap run

Then allow the microphone, say “Jarvis” and try “what time is it?”, “abre Notas” or “what's 18% of 2,450?”. Full guide: docs/SETUP.md.
